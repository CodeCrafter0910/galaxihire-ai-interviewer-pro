## 💡 Quick Summary (30 seconds):

**"GalaxiHire is an AI-powered interview platform built with Next.js frontend and Node.js backend. It conducts automated interviews with 22 questions across 4 stages (Aptitude, Coding, Technical, HR). Candidates can answer via voice, video, or text. We use Groq AI for question generation and evaluation, Whisper for speech-to-text, and MongoDB for data storage. The system generates detailed PDF reports with scores and feedback."**

---

## 🔑 Key Points to Remember:

### Frontend:
- Next.js (React framework)
- Components: AudioRecorder, VideoRecorder, CodeEditor
- Uses WebRTC for audio/video capture
- Axios for API calls

### Backend:
- Node.js + Express
- MongoDB database
- JWT authentication
- Services: llmService, whisperService, reportGenerator

### AI:
- Groq AI (LLaMA 3) - Question generation & evaluation
- Whisper - Speech-to-text
- Python FastAPI - Audio/video analysis

### Flow:
1. User registers → JWT token
2. Upload resume → AI extracts skills
3. Start interview → AI generates questions
4. Answer (voice/video/text) → AI evaluates
5. Complete → Generate PDF report
