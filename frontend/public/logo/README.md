# Logo Setup Instructions

## Save Your Logo Image

Please save your GalaxiHire logo image as:
```
galaxihire-logo.png
```

in this directory (`frontend/public/logo/`).

## Image Requirements

- **Format**: PNG (recommended for transparency)
- **Recommended dimensions**: 
  - Width: 400-600px (will be scaled automatically)
  - Height: 100-150px
  - Aspect ratio: Maintain the original logo proportions
- **Background**: Transparent background recommended for best results

## Where the Logo is Used

The logo has been updated in the following locations:
1. **Sidebar** - Dashboard navigation (left side)
2. **Login Page** - Both desktop and mobile views
3. **Register Page** - Both desktop and mobile views

## After Saving the Logo

Once you save the logo image in this directory, refresh your browser to see the new logo throughout the application.

## Fallback

If the logo doesn't appear immediately:
1. Clear your browser cache
2. Restart the development server
3. Check that the filename is exactly: `galaxihire-logo.png`
